# DevOps Class – Frontend (Code Only)

Minimal Vite + React app **without** CI/CD artifacts or build scripts.
Your task: create the CI pipeline, add build/test/lint steps, and define deploy.

## Run locally
- `npm install`
- `npm run dev`

## Add in your pipeline
- Build task (vite build) and artifacts
- Test task (Vitest)
- Lint task (ESLint/Prettier)
- Deploy (e.g., static host or container)# devops-class-frontend
